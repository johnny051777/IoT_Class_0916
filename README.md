## Features

- **Personal Profile**: Customizable display name, dynamic avatar initials, status indicator, and personal tagline.
- **Current Time+ Engine**:
  - Real-time digital clock (Hours:Minutes:Seconds) with 12H/24H format toggling.
  - Date, week of the year, dynamic time-of-day greeting, and daylight progress tracking.
  - Local timezone detection with UTC offset display.
- **World Clocks**: Live time tracker for Tokyo, Singapore, London, New York, and San Francisco.
- **Stopwatch & Focus**: Millisecond stopwatch with lap tracking.
- **Launchpad**: Direct links to GitHub repository, profile, and development documentation.
- **Daily Focus Scratchpad**: Auto-saving note box and curated inspirational quotes on time.
- **Themes**: Switchable palettes including Obsidian Dark, Cyberpunk Neon, Sunset Amber, and Emerald Matrix.
